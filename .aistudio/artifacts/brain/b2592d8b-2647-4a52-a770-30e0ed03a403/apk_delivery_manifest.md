## Core Capabilities Included
1. **Chrome-Style Find Bar**: Query input, dynamic match count badge (e.g. 3/14), previous/next navigation with wrap-around, Case Sensitive (`Aa`), Whole Word (`"Word"`), and Regex (`.*`) modes.
2. **On-Device OCR**: Offline Google ML Kit Vision Text Recognition supporting Latin and Devanagari (Hindi, Marathi, Sanskrit) scripts.
3. **Document Find**: Text viewer for plain text (`.txt`), multi-page rendered PDFs (`PdfRenderer`), and images (`image/*`) with interactive bounding box overlays and vertical mini-map tick marks.
4. **Screen Capture & Accessibility**: `MediaProjection` screen frame extraction and optional `AccessibilityService` view hierarchy node search.
5. **Floating Overlay Widget**: `FloatingSearchService` with `SYSTEM_ALERT_WINDOW` support.
6. **Diagnostics & Latency Benchmark**: Hardware telemetry, OCR status check, and live 1,000-pass search latency benchmark.
